## 1. 개요 및 사용자 피드백 핵심 진단

사용자 피드백을 정밀 분석한 결과, 아래 네 가지 핵심 요구사항 및 기술적 개선 방향을 도출하였습니다.

### 🔍 진단된 핵심 과제
1. **차수 엉킴 (Re-indexing 오류 해결)**:
   - 예약 매수 체결 시마다 `enumerate`로 전체 미청산을 덮어써서 원래 **25차**였던 바닥 Rebase 행이 16차, 17차 등으로 강제 강등되던 버그 제거.
2. **차수 역순 배정 (바닥 Rebase 기준 -1씩 카운트다운)**:
   - 바닥(25차, 최저가)에서 위로 반등할 때 가장 먼저 체결되는 바닥 바로 위 가격은 당연히 **`24차` (25 - 1)**가 되어야 함.
   - 사용자 지적대로 **"바닥 rebase 차수에서 -1씩 줄어드는 역순 카운트다운"**이 그리드 가격-차수 대원칙(`차수가 클수록 가격이 낮다`)과 100% 일치.
3. **단일 통합 텔레그램 알림**:
   - 일반 그리드 매수 메시지(`🚨[그리드롱 진입 완료]`)와 공백 복원 메시지를 쪼개지 않고, 손익 블록과 보유금 라인이 포함된 **단 하나의 표준 종합 메시지**로 통합 발송.
4. **미매도 차수 점검 로직 신설 (신규 요구사항) ⭐**:
   - **발동 시점**:
     - ① 예약 매수가 모두 소진/완료되었을 때 (`rem_count == 0`)
     - ② 현재가가 쿨링 전 마지막 매수가($P_{prev}$) 이상으로 높아져 예약이 취소되었을 때 (`현재가 >= P_prev`)
     - ③ 다음 예약가가 $P_{prev}$에 0.7% 이내 근접하여 잔여 예약이 자동 취소되었을 때
     - ④ 쿨링 전 상위 차수 익절 매도로 잔여 예약이 클리어되었을 때
   - **수행 작업**:
     - **중간 결번(Gap) 압축 재정렬**: 예컨대 1~14차와 23~25차만 체결되고 15~22차가 취소된 경우, 미매도 포지션을 가격 내림차순 기준으로 `1차 ~ 17차`로 빈틈없이 압축 재정렬하여 일반 그리드 모드로의 안전한 복귀 보장.
     - **거래소 실포지션 대조**: 엑셀 미매도 수량 총합과 비트겟 실제 보유 포지션 수량(`fetch_positions`) 1:1 대조.
     - **가격 역전 검사**: 모든 차수의 가격 내림차순 무결성 검증.
     - **다음 매수 기준 확정**: 최하위 N차 기준의 `N+1차` 신규 하락 매수 목표가 산출.
     - **텔레그램 미매도 점검 종합 리포트 발송**.

## 2. 가격-차수 매핑 및 반등 체결 구조표

> **[상황 가정]**
> * 쿨링 전 1~24차 보유 (최하위 24차: $140.83)
> * 쿨링 해제 후 Rebase 첫 매수 체결: **$125.88** (공백 발생 ➔ 상위 1~10차 손절, $K=10$)
> * 잔여 11~24차 ➔ **1차 ~ 14차**로 Re-indexing ($140.83 이상 고정)
> * 바닥 Rebase ($125.88) ➔ **25차** 확정 ($M + K + 1 = 14 + 10 + 1 = 25$)

| 가격대 | 차수 번호 | 성격 | 반등 체결 순서 및 공식 | 비고 |
| :---: | :---: | :---: | :--- | :--- |
| **$140.83 이상** | **1차 ~ 14차** | 기존 보유분 (총 14개) | 고정 유지 (재정렬 금지) | 기존 물량 |
| **약 $134.69** | **15차** | 공백 예약 최상단 | 10번째 반등 체결: `25 - 10 = 15차` | 예약 매수 |
| **...** | **...** | ... | ... | ... |
| **약 $127.64** | **23차** | 공백 예약 | 2번째 반등 체결: `25 - 2 = 23차` | 예약 매수 |
| **약 $126.76** | **24차** | 공백 예약 최하단 | **1번째 반등 체결: `25 - 1 = 24차`** ⭐ | 예약 매수 |
| **$125.88** | **25차** | **바닥 Rebase 체결분** | **쿨링 직후 체결 완료 (기준점)** | 바닥 보유분 |
| **약 $125.00** | **26차** | **추가 하락 시 진입** | **바닥 아래 추가 하락: `25 + 1 = 26차`** | 신규 하락 |

## 3. 미매도 차수 점검 로직 상세 설계 (`공백복원_종료_미매도차수_점검`)

### 🛠️ 동작 알고리즘
```python
def 공백복원_종료_미매도차수_점검(Ticker: str, 사유: str, 현재가: float = 0.0) -> None:
    """
    공백 복원이 완료되거나 취소/만료되는 시점에 호출되어:
    1) 엑셀 스냅샷 백업
    2) 미청산(미매도) 포지션을 매수가 내림차순으로 정렬하여 1차부터 N차까지 빈틈없이 결번 압축 재정렬
    3) 비트겟 거래소 실제 롱 포지션 수량(fetch_positions)과 엑셀 미매도 총 수량 1:1 대조
    4) 가격 내림차순 정합성(가격 역전 여부) 검증
    5) 최하위 N차 기준 다음 신규 하락 매수 목표가(N+1차) 산출
    6) 공백 복원 상태 완전 클리어 및 텔레그램 종합 점검 리포트 발송
    """
```

### 📊 시나리오별 차수 압축 예시
- **상황**: 24차($126.76)와 23차($127.64)만 체결된 후 시세가 급등하여 기준가($P_{prev} = $140.83)를 돌파함.
- **점검 전 엑셀 차수**: `1~14차` (14개) + `23차, 24차, 25차` (3개) ➔ **15~22차 결번 존재 (총 17개 포지션)**.
- **점검 로직 실행 후**:
  - `1~14차` ➔ 1~14차 유지
  - `23차 ($127.64)` ➔ **15차**로 압축
  - `24차 ($126.76)` ➔ **16차**로 압축
  - `25차 ($125.88)` ➔ **17차**로 압축
  - ➔ **결과**: 현재 보유 차수는 완벽한 **`1차 ~ 17차`**가 되며, 이후 추가 하락 시 **`18차`**로 깔끔하게 진입!

## 4. `Grid_Bitget.py` 상세 수정 계획

### 수정 1. `쿨링공백복원_실행` 상태 저장 개선
- `base_level` (바닥 Rebase 차수, 예: 25)을 상태에 명확히 저장.
- 첫 예약 매수 `step: 1` 등록.

### 수정 2. `공백복원_예약매수_감시` 차수 역순 배정 및 단일 통합 알림 적용
- 무차별 `enumerate` 덮어쓰기 코드 제거.
- **역순 공식 적용**: `assigned_level = rebase_level - current_step` (24차, 23차...).
- 예약 매수 체결 시 일반 그리드 매수 표준 템플릿(손익블록, 보유금라인 포함)의 단일 메시지 발송.
- 계획 횟수 소진 완료 시점(`rem_count == 0`) 및 기준가 근접 취소 시점에 `공백복원_종료_미매도차수_점검()` 호출.

### 수정 3. 기준가 상향 돌파 시점 및 매도 클리어 시점 점검 로직 연동
- 현재가 $\ge P_{prev}$ 상향 돌파 만료 시 `공백복원_종료_미매도차수_점검()` 호출.
- 쿨링 전 상위 차수 익절 매도 체결 시 `공백복원_종료_미매도차수_점검()` 호출.

### 수정 4. 일반 그리드 루프 격리 및 추가 하락 시 보호
- 공백 복원 진행 중에는 일반 루프가 공백 차수를 건드리지 못하도록 방어.
- 바닥 아래 추가 하락 시에는 최하위 기준의 `rebase_level + 1` (26차)로 진입.
