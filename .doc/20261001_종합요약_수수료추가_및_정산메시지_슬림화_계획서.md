# 📋 종합 요약 수수료 추가 및 정산 메시지 최종 슬림화 계획서

## 1. 개요 및 반영 사항
사용자의 요청 사항들을 종합하여 최종 메시지 포맷을 완성합니다:
1. **SOXL 단일 종목 집중**: 각 섹션마다 중복 표시되던 `📊 합계` 블록을 제거하고 SOXL 내역만 깔끔하게 표시
2. **누적수익 위치 논리화**:
   - 일일/주간/월간은 해당 구간의 `실현수익`을 표시
   - 4번 전체 정산에서 봇 시작 이래의 `누적수익`을 명확하게 표시
3. **종합 요약에 수수료 정보 추가**:
   - 하단 `[구간별 종합 요약]`에 구간별 실현수익뿐만 아니라 **발생 수수료(USDT)** 정보를 함께 표기하여 순수익 체감 및 비용 추적을 용이하게 개선

## 3. 코드 구현 세부 사항 (`Grid_Bitget.py`)

### 1) `_포맷_정산_섹션` 함수 개선
- `profit_label` 파라미터를 추가하여 1~3번 섹션은 `"실현수익"`, 4번 전체 섹션은 `"누적수익"`으로 라벨 표기
- 단일 종목 운용 시 중복되던 `📊 합계` 블록은 생략하여 메시지 압축
