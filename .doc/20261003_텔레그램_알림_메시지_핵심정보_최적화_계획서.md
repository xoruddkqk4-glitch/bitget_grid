# 텔레그램 알림 메시지 핵심 정보 최적화 계획서 (2차 보완)

본 문서는 사용자의 추가 피드백을 반영하여 **비트겟 그리드봇(`Grid_Bitget.py`)**의 텔레그램 알림 메시지를 더욱 군더더기 없이 핵심 정보 중심으로 최적화하기 위한 구현 계획서입니다.

> [!NOTE]
> 본 작업은 `/ask` 모드로 진행되므로, 계획서 확인 후 **`/apply`** 명령어를 입력해 주시면 소스 코드에 즉시 반영됩니다.

---

## 1. 요구사항 분석 및 2차 변경 사항 요약

| 메시지 구분 | 기존 문제점 및 사용자 피드백 | 최종 개선 방향 |
| :--- | :--- | :--- |
| **1. 진입(매수) 완료** | 트레일링/목표가/트리거/미실현/사이클 손익 등이 과도하게 표시됨 | 불필요 항목 전부 삭제 → **종목, 차수, 시장가, 체결가, 슬리피지, 수량, 체결금액, 시간**만 유지 |
| **2. 청산(매도) 완료** | ① 트레일링 고정 조건(`1차+0.7%/2차+0.9%`) 불필요<br>② `누적 실현손익`과 `엑셀 누적실현` 중복<br>③ `baseline` 및 `총합(참고)`로 인한 메시지 난잡함 | ① 트레일링 기준값 제거 (`고점/매도선/청산시`만 표시)<br>② **실현 손익 강조** (`✨ 【 실현 손익 】: +1.0774 USDT (+0.7590%)`)<br>③ **`누적 실현손익`, `엑셀 누적실현`, `baseline`, `총합(참고)` 4개 항목 전격 삭제**<br>④ 핵심 사이클 정보(`사이클`, `미실현`, `사이클 수익/목표`)만 깔끔하게 유지 |
| **3. 종합 정산** | 각 기간별(일일/주간/월간/전체) 매도 1회당 평균 수익 부재 | 각 섹션 및 요약부에 **`매도 1회 평균 실현 손익`** 지표 신규 추가 |

### 1) `총수익_텔레그램라인` 함수 다이어트 ([Grid_Bitget.py:1295-1307](file:///c:/Users/user/Desktop/trading_buddy/06비트겟자동매매-4기/week_01-bitget_grid/Grid_Bitget.py#L1295-L1307))
- `엑셀 누적실현`, `baseline`, `총합(참고)` 줄을 제거하여 핵심 사이클 정보만 반환:
```python
def 총수익_텔레그램라인(Ticker: str, 현재가: float) -> str:
    """텔레그램에 붙이는 총수익 요약 블록 (사이클 핵심 정보만 표시)"""
    미실현, 누적실현, 총합, baseline, 사이클 = 총수익_계산(Ticker, 현재가)
    회차 = 총수익_사이클회차_조회(Ticker)
    return (
        f"🔁 *사이클*: `{회차}회차`\n"
        f"💰 *미실현*: `{미실현:+.4f} USDT`\n"
        f"🎯 *사이클 수익*: `{사이클:+.4f} USDT` "
        f"(목표 {TOTAL_PROFIT_TARGET_USDT} USDT)\n"
    )
```
