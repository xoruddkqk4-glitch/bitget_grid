# 비트겟 그리드롱 자동매매 봇 (Bitget Grid Long Trading Bot)

비트겟(Bitget) 선물 시장에서 지정된 그리드 간격과 트레일링 스탑(Trailing Stop)을 활용하여 안정적인 분할 매수 및 익절을 수행하는 자동매매 프로그램입니다.

---

## 📌 주요 기능

1. **그리드 분할 매수 (Grid Entry)**
   - 설정된 간격(%) 및 차수별 투입 금액에 따라 순차 분할 매수
   - 3음봉 필터링 및 RSI 지표 기반 진입 필터 지원
   - 급락 연쇄 매수 방지 쿨링 및 재개 시 저점 반등 하이브리드 리베이스(Rebase) 지원

2. **독립 슬롯 트레일링 스탑 익절 (Trailing Stop Exit)**
   - 각 차수별 독립적인 목표 수익률 및 트레일링 스탑 추적
   - 차수 내림차순(8차 ➔ 7차 ➔ 6차 ...) 우선 익절로 최저점 고수익 물량 우선 수익 확정

3. **총수익 목표 달성 자동 청산 (Total Profit Target)**
   - 미실현 손익과 누적 실현 손익의 합이 사이클 목표치에 도달하면 전 차수 일괄 청산
   - 청산 후 모드 설정 지원 (`STOP`, `PAUSE`, `RESTART`)

4. **엑셀 기반 상태 저장 및 텔레그램 알림**
   - 엑셀 파일을 통한 완벽한 비휘발성 포지션 및 손익 추적
   - 매수, 매도, 쿨링, 청산 완료 시 실시간 텔레그램 상세 리포트 전송
   - 매일 KST 09시 기준 일일/주간/월간/전체 기간별 실현손익 및 수수료 통합 정산 리포트 자동 발송

---
